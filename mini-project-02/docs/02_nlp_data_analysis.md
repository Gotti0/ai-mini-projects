## 1. 검색 데이터셋 구조 (CP-01)

- **데이터 출처:** KLUE-MRC의 Validation 데이터에서 재구성한 교육용 검색 데이터
- **Corpus:** 200개 문단
- **Validation / 보류 Test:** 질문 60개 / 20개
- **질문과 정답 문서의 연결 기준(`relevant_doc_id`):** KLUE-MRC 원 데이터에서 각 질문의 정답 구간이 포함된 단일 문단(정답 주변 500자 이내)을 고유 문서 ID(`D000`~`D199`)로 1:1 연결했다.
- **Validation과 Test가 동일한 Corpus를 사용하는 의미:** 실제 검색 시스템처럼 문서 저장소(200개 문단)를 고정한 상태에서, 모델 비교·선정에 사용한 Validation 질문과 처음 보는 보류 Test 질문을 동일한 검색 공간에서 공정하게 비교·검증하기 위함이다.

> 아래 분석에서는 Corpus와 Validation 질문만 사용합니다. 보류 Test 질문은 CP-10에서 평가합니다.

## 2. 문서·질문 길이 분석 (CP-01)

`corpus_stats['char_length']`와 `valid_stats['char_length']`의 통계 및 히스토그램을 참고합니다. 단위는 토큰 수가 아닌 글자 수입니다.

| 구분 | 평균 | 중앙값 | 최소 | 최대 |
|---|---:|---:|---:|---:|
| Corpus 문서 | 499.66 | 500 | 498 | 500 |
| Validation 질문 | 29.22 | 28 | 13 | 54 |

**분석:** 문서와 질문의 길이 분포에서 관찰한 특징과 그 특징이 검색에 영향을 줄 가능성을 작성합니다.  
Corpus 문서는 정답 구간 주변 500자 이내로 절단되어 있어 최소 498자, 최대 500자로 길이가 매우 균일했다. 반면 Validation 질문은 최소 13자에서 최대 54자(평균 29.22자, 중앙값 28자)로 상대적으로 짧고 넓게 퍼져 있었으며, 질문과 문단 사이에 약 17배의 길이 비대칭이 존재했다. 이 때문에 문서 길이 차이로 인한 편향은 크지 않지만, 아주 짧은 질문은 500자 문단 전체에서 정답 단서가 희석되거나 유사 주제의 다른 문서와 혼동될 가능성이 있고, BERT 계열에서는 문단 토큰 수가 최대 길이를 넘지 않도록 관리하고 짧은 질문의 패딩(`[PAD]`)을 평균에서 제외하는 Masked Mean Pooling이 중요해진다.

## 3. 질문–정답 문단의 문자 겹침 비율 (CP-01)

`valid_overlap`은 질문의 어절 내부 고유 문자 2-gram 중 정답 문단에도 등장하는 비율입니다. TF-IDF 유사도 점수와는 다릅니다.

- **Validation 전체 겹침 비율의 평균 / 중앙값:** 0.474 / 0.462
- **겹침 비율의 최소 / 최대:** 0.158 / 0.882
- **겹침 비율이 낮은 대표 질문 1개(ID / 질문 / 겹침 비율):** QV009 / 영국은 어느나라와의 싸움에서 승리해 코이누르 보석을 습득했나요? / 0.227
- **해당 정답 문단에서 확인한 표현 차이:** 정답 문단(`D000`)에서는 `코이누르 다이아몬드`로 표기되어 있으나 질문에서는 `코이누르 보석`으로 상위 개념으로 바꿔 표현했고, 사건 경위도 본문 어휘를 그대로 쓰지 않고 `싸움에서 승리해 습득했나요?`처럼 풀어 써서 표면 문자 2-gram 겹침이 낮았다.

**분석:** 겹침 비율 분포에서 발견한 특징을 작성합니다.  
Validation 60문항의 문자 2-gram 겹침 비율은 평균 0.474, 중앙값 0.462(25% 0.333, 75% 0.601)로 대체로 질문 어휘의 절반 가까이가 정답 문단에도 그대로 등장했다. 상위 25%는 본문 표현을 그대로 공유해 표면 어휘 일치만으로도 검색에 유리한 반면, 하위 25%(0.333 이하, 최소 0.158)는 본문 내용을 다른 단어로 바꿔 물어보는 의역형 질문이 섞여 있어 표면 일치 기반 검색과 의미 기반 검색의 성능 차이가 벌어질 여지가 보였다.

## 4. 검색 성능에 대한 초기 가설 (CP-01)

- **가설 ① TF-IDF가 유리할 것으로 예상하는 질문 유형과 이유:** 본문 표현을 그대로 사용한 질문은 질문–정답 문단 간 문자 겹침 비율이 높으므로, 표면 어휘 일치와 문자 n-gram 가중치에 기반한 TF-IDF 방식이 유리할 것으로 예상했다.
- **가설 ② BERT 기반 검색이 유리하거나 불리할 것으로 예상하는 질문 유형과 이유:** 본문 내용을 다른 말로 바꿔 물어본 질문은 질문–정답 문단 간 겹침 비율이 낮아 표면 일치만으로 찾기 어렵기 때문에, 문맥과 의미를 벡터로 반영하는 BERT 기반 검색 방식이 유리할 것으로 예상했다.
