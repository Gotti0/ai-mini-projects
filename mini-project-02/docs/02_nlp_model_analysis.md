## 1. 검색기 구현 및 임베딩 확인 (CP-02~CP-06, CP-08)

| 검색 방식 | 사용 모델·표현 방식 | 전체 문서 벡터 Shape |
|---|---|---|
| TF-IDF | 문자 2~3-gram, `max_features=30000` | `(200, ≤30000)` (희소 행렬) |
| BERT | `klue/bert-base` + Masked Mean Pooling | `(200, 768)` |
| Sentence-BERT | `snunlp/KR-SBERT-V40K-klueNLI-augSTS` | `(200, 768)` |

- **BERT Encoder 출력 / Attention Mask / Pooling 결과 Shape (CP-03~04의 질문 2개):** `(2, 19, 768)` / `(2, 19)` / `(2, 768)`
- **BERT와 Sentence-BERT의 최대 입력 길이:** 256토큰
- **Padding을 평균 계산에서 제외하는 이유:** `attention_mask`가 0인 위치는 배치 내 최대 길이에 맞추기 위해 채워 넣은 의미 없는 `[PAD]` 토큰이므로, 이를 포함해 평균하면 `[PAD]` 위치의 출력 벡터가 노이즈로 섞이고 분모(토큰 수)도 커져 실제 문장 벡터가 왜곡된다.
- **BERT와 Sentence-BERT 문서 벡터를 혼합하지 않는 이유:** 두 모델은 출력 차원(768)은 같지만 학습 목적(MLM vs NLI·STS)과 파라미터가 달라 서로 다른 임베딩 공간에 매핑되므로, 서로 다른 모델의 질문 벡터와 문서 벡터를 직접 코사인 유사도로 비교할 수 없다.
- **Pooling·코사인 유사도·검색 결과 검증 셀 실행 결과:** CP-02(TF-IDF·Top-k), CP-04(Padding 제외 평균), CP-05(코사인 유사도·BERT 문서 임베딩), CP-06(TF-IDF/BERT Top-k 검색기)의 모든 `[공통 검증]` 셀을 통과했다.

## 2. 검색 평가 기준 (CP-07)

- **평가에 사용하는 검색 결과:** Top-5 문서
- **질문별 지정된 정답 문서 수:** 1개
- **Hit@1이 평가하는 내용:** 검색 결과의 최상위 1위 문서가 정답 문서와 정확히 일치하는 비율을 평가한다(정답이 1위면 1, 아니면 0).
- **Recall@3이 평가하는 내용:** 검색 결과 상위 3개 문서 안에 정답 문서가 포함되었는지 비율을 평가한다(단일 정답 구조이므로 상위 3개에 포함되면 1, 아니면 0).
- **MRR@5가 평가하는 내용:** 상위 5개 결과 안에서 정답 문서가 처음 등장한 순위의 역수(`1 / rank`, Top-5 밖이면 0)를 평균해, 정답이 더 높은 순위에 배치될수록 높은 점수를 부여한다.
- **검색 지표 단위 테스트 결과:** `[공통 검증] CP-07`에서 2위 정답(`Hit@1=0, Recall@3=1, MRR@5=0.5`), 1위 정답(`Hit@1=1`), Top-5 미포함(`MRR@5=0`) 케이스를 모두 통과했다.

## 3. 세 검색 방식의 성능 비교 (CP-07~CP-08)

`comparison_df`의 Validation 결과를 기록합니다.

| 검색 방식 | Hit@1 | Recall@3 | MRR@5 |
|---|---:|---:|---:|
| TF-IDF | 0.8833 | 0.9667 | 0.9167 |
| BERT | 0.6667 | 0.8333 | 0.7589 |
| Sentence-BERT | 0.7667 | 0.8833 | 0.8208 |

**분석:** 지표별 성능 차이와 예상과 달랐던 결과가 있다면 그 가능 원인을 작성합니다.  
Validation 60문항에서 TF-IDF가 Hit@1 0.8833, Recall@3 0.9667, MRR@5 0.9167로 세 지표 모두 가장 높았고, Sentence-BERT(0.7667 / 0.8833 / 0.8208)가 2위, 일반 BERT(0.6667 / 0.8333 / 0.7589)가 가장 낮았다. Sentence-BERT는 일반 BERT 대비 Hit@1 +0.1000, Recall@3 +0.0500, MRR@5 +0.0619 향상되어 문장 유사도(NLI·STS) 학습의 효과가 확인되었으나, 딥러닝 모델이 TF-IDF를 앞설 것이라는 통념과 달리 TF-IDF가 전 지표에서 우세했다. 이는 KLUE-MRC 기반 질문과 정답 문단 사이에 고유명사·숫자·핵심 어휘 겹침(평균 0.474)이 많아 문자 2~3-gram 기반 TF-IDF가 매우 유리했고, 일반 BERT는 문장 검색용으로 학습되지 않아 Mean Pooling만으로는 코사인 유사도 변별력이 떨어졌으며, KR-SBERT 역시 짧은 문장 쌍 유사도 위주로 학습되어 짧은 질문(평균 29.2자)과 긴 문단(약 500자)의 비대칭 검색 및 세밀한 고유명사 구분에서는 TF-IDF보다 불리했을 가능성이 있기 때문으로 분석된다.

- **겹침 비율이 낮은 대표 질문에서 상대적으로 잘 검색한 방식(관찰 가능한 범위):** 겹침 비율이 낮은 QV018(0.158)과 QV035(0.278)에서 모두 1위를 기록하고 QV047(0.333)에서도 유일하게 Top-5(4위)에 든 Sentence-BERT가 저겹침 질문에서 상대적으로 강점을 보였다.

**가설 검증:** `02_nlp_data_analysis.md`의 4절에서 세운 두 가설이 실제 결과와 일치했는지, 검색 순위와 문서 내용에 근거하여 작성합니다.  
가설 ①(본문 표현을 그대로 쓴 높은 겹침 질문에서 TF-IDF가 유리하다)은 평균 겹침 비율이 0.474로 높은 본 데이터셋에서 TF-IDF가 Hit@1 0.8833, Recall@3 0.9667, MRR@5 0.9167로 세 모델 중 가장 높은 성능을 기록하며 명확히 확인되었다. 반면 가설 ②(바꿔 물어본 낮은 겹침 질문에서 BERT 계열이 유리하다)는 부분적으로만 일치했다. 문장 유사도 학습을 거친 Sentence-BERT는 실제로 저겹침 질문(QV018, QV035)에서 TF-IDF의 약점을 보완하며 1위를 기록했지만, 일반 BERT(`klue/bert-base`)는 검색용으로 학습되지 않아 저겹침 질문에서도 뚜렷한 우위를 보이지 못했고 전체 성능(Hit@1 0.6667)도 가장 낮았다.

## 5. 최종 검색기 및 Test 평가 (CP-10)

- **Test 평가 전에 확정한 검색 방식(`SELECTED_METHOD`):** `tfidf`
- **직접 입력한 새로운 질문:** `전기차 배터리 용량과 관련된 내용이 담긴 문서는 무엇인가요?`
- **`search_docs()`의 Top-3 문서 ID와 검색 결과에서 관찰한 점:** `D092`(0.2412), `D020`(0.0614), `D050`(0.0425) 순으로 반환되었다. 전기차·배터리 관련 본문을 담은 `D092`가 2·3위 문서 대비 약 4배 높은 유사도로 1위에 정확히 검색되어, 핵심 키워드가 명확한 새로운 질문에서 TF-IDF가 뚜렷한 변별력을 보임을 확인했다.

동일한 검색 방식에서 `final_compare`의 결과를 기록합니다.

| 데이터 | 질문 수 | Hit@1 | Recall@3 | MRR@5 |
|---|---:|---:|---:|---:|
| Validation | 60 | 0.8833 | 0.9667 | 0.9167 |
| 보류 Test | 20 | 0.8000 | 0.8000 | 0.8125 |

**해석:** Validation과 Test의 지표 차이를 실제 수치로 비교하고, Test에서 실패한 질문의 특징과 예상 원인을 작성합니다.  
최종 선정한 TF-IDF 모델은 Validation 60문항에서 Hit@1 0.8833, Recall@3 0.9667, MRR@5 0.9167을 기록했고, 보류 Test 20문항에서는 Hit@1 0.8000(16/20), Recall@3 0.8000(16/20), MRR@5 0.8125로 전 지표가 하락했다(특히 우선 지표인 Recall@3 -0.1667p). 이는 Validation 기준으로 모델을 선정하며 생기는 선택 편향과 더불어 Test 표본이 20문항뿐이라 1문항당 0.05(5%p)씩 크게 변동하는 소표본 분산이 함께 작용한 결과로 보인다. Test에서 1위 검색에 실패한 4건은 `QT003`(Top-5 밖), `QT009`(Top-5 밖), `QT012`(4위), `QT016`(Top-5 밖)이었으며, 특히 `QT016`("투자에 적극적인 인물의 이름은?")처럼 매우 짧고 범용 표현 위주이거나 `QT003`·`QT009`처럼 질문 표현과 본문 표기가 어긋나는 경우 점수가 낮아져 `QT003`과 `QT016` 모두 동일한 오답 문서(`D198`)가 1위로 검색되었다. 이는 CP-09에서 확인한 TF-IDF의 한계(짧은 일반 질문 및 표면 단어 불일치 취약)가 새로운 질문에서도 재현된 결과였다.

**평가의 한계:** 동일한 Corpus에서 새로운 질문을 평가했다는 점, 데이터 규모와 질문별 단일 정답 문서의 한계를 고려하여 실제 업무 검색에서 추가로 확인할 점을 작성합니다.  
본 실험은 200개 문단의 소규모 고정 Corpus를 그대로 둔 채 Test 20문항만 새로 평가했으므로 통계적 신뢰구간이 넓고, 수만~수백만 문서 규모에서 발생하는 유사 문서 간섭과 인덱싱·응답 지연(latency)을 반영하지 못한다. 또한 모든 문단을 정답 주변 500자로 균일하게 자르고 질문당 정답 문단도 1개로 고정한 통제 조건이므로, 실제 업무 적용 전에는 ① 길이가 불균일한 원본 문서와 다중 정답·정답 없음 질의가 포함된 실무 도메인 평가셋 구축, ② 오타·약어·구어체·의역 질문 비율 측정, ③ TF-IDF 단독 대비 SBERT 결합 하이브리드 검색의 정확도와 실제 CPU/GPU 응답 시간 실측을 추가로 검증해야 한다.
