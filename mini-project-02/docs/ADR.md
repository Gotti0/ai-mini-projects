## NLP — BERT 기반 한국어 의미 검색 시스템 개발 및 성능 비교

### 의사결정 ① 활용 목적과 우선 평가 지표 선택 (CP-07~CP-09)

**문제**

검색 시스템의 활용 목적에 따라 첫 번째 검색 결과의 정확성, 상위 후보에 정답이 포함되는지, 정답 문서의 순위 중 무엇을 더 중요하게 평가할지 결정해야 합니다.

- **가정한 활용 상황(`USE_CASE`):** 사용자가 한국어 문서 집합에서 사실 확인형 질문을 입력했을 때 정답이 담긴 근거 문단 상위 3건을 빠르게 제공하는 문서 검색 및 RAG 1차 검색기
- **검토한 지표:** Hit@1, Recall@3, MRR@5
- **최종 우선 평가 지표(`PRIORITY_METRIC`):** `recall3` (Recall@3)
- **선택 근거(사용자가 검색 결과를 어떻게 활용하는지):** 사용자가 상위 3개 추천 문단을 직접 확인하거나 RAG 시스템이 상위 3개 문단을 근거 컨텍스트로 받아 답변을 생성하는 구조에서는, 정답 문단이 1위에 오지 않더라도 상위 3개 후보 안에 누락 없이 포함되는지가 최종 품질을 좌우한다.
- **함께 고려할 다른 지표 또는 제약:** 상위 3개 안에서도 정답이 1위에 가까울수록 탐색 효율과 답변 정확도가 높아지므로 `Hit@1`과 `MRR@5`를 보조 지표로 함께 점검해야 하며, 실제 운영 시에는 대규모 문서에서의 응답 시간과 메모리 제약도 추가로 확인해야 한다.

**분석 근거:** `02_nlp_model_analysis.md`의 2~4절

### 의사결정 ② 최종 검색 방식 선택 (CP-09)

**문제**

문자 기반 TF-IDF, 일반 BERT의 Mean Pooling, Sentence-BERT 검색 방식의 성능과 특성을 비교하여 최종 검색기를 선택해야 합니다.

- **비교한 선택지:** TF-IDF / BERT / Sentence-BERT
- **최종 선택한 검색 방식(`SELECTED_METHOD`):** `tfidf`
- **선택 근거(`SELECTION_REASON`, 실제 Validation 수치와 검색 실패 사례를 활용):** Validation 60문항에서 TF-IDF가 Hit@1 0.8833, Recall@3 0.9667, MRR@5 0.9167로 Sentence-BERT(0.7667/0.8833/0.8208)와 일반 BERT(0.6667/0.8333/0.7589)를 모든 지표에서 앞섰다. Sentence-BERT는 QV018과 QV035처럼 어휘 겹침이 낮은 의역 질문에서 1위를 맞히는 강점이 있었으나 우선 지표인 Recall@3가 0.0833p 낮았고, 일반 BERT는 문장 유사도 학습이 없어 변별력이 가장 낮았으므로 현재 코퍼스에서는 TF-IDF를 최종 선정했다.
- **트레이드오프(다른 방식과 비교해 얻은 장점과 감수한 단점):** 고유명사·숫자·핵심 어휘가 본문과 겹치는 사실 확인형 질문에서 가장 높은 정확도(`Recall@3 0.9667`)와 단순한 구성(별도 신경망 추론 불필요)을 얻었다. 대신 QV018(겹침 0.158)과 QV035(겹침 0.278)처럼 본문 표현을 다른 말로 풀어 쓴 의역 질문에서는 Sentence-BERT보다 순위가 밀리는 단점을 감수했다.
- **추후 확인할 점(실제 사용 데이터, 검색 처리 비용 등):** 실제 서비스 환경의 대용량 문서(수만 건 이상)와 의역·오타·약어가 많은 도메인 질의에서의 성능 변화, CPU/GPU 환경별 실제 쿼리 응답 시간(latency) 및 인덱싱 비용, 그리고 TF-IDF와 Sentence-BERT를 결합한 하이브리드 검색(또는 2단계 재정렬)의 효용을 추가로 검증해야 한다.

**분석 근거:** `02_nlp_data_analysis.md`, `02_nlp_model_analysis.md`의 3~4절, `outputs/reports/cp09_selection.json`
